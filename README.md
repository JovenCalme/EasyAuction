## 简体中文

### 插件简介

EasyAuction 是一款专为魔兽世界泰坦经典服设计的拍卖行增强插件，提供一键购买、自动填写价格、历史价格查询等强大功能，帮助玩家更高效地进行拍卖行交易。

### 功能清单

- **闪卖助手**：自动填写参考价格，支持一键上架
- **价格数据库**：完整的历史价格记录与趋势分析
- **价格走势图**：可视化查看物品价格波动
- **分解价值**：显示物品分解后材料的预估价值
- **购物清单**：支持多清单管理、导入导出
- **策略上架**（Pro功能）：按策略自动生成上架方案
- **运营维护**（Pro功能）：检查拍卖状态、记录交易账本
- **主题切换**：多种界面风格可选

### 支持版本

- 魔兽世界泰坦经典服 (Interface: 38001)

### 安装教程

1. 下载最新版本的插件压缩包
2. 解压到 `World of Warcraft/_classic_titan_/Interface/AddOns/` 目录
3. 确保解压后目录结构为 `AddOns/EasyAuction/EasyAuction.toc`
4. 启动游戏，在角色选择界面确认插件已启用

### 使用方法

**基础操作**：
- 打开拍卖行后，插件自动加载
- 点击物品可查看历史价格和分解价值
- 闪卖面板支持快速填写价格并上架

**命令**：
- `/epah` - 打开价格数据库
- `/easyauction` - 打开设置面板

## English

### Addon Description

EasyAuction is an auction house enhancement addon designed for World of Warcraft Titan Classic, providing powerful features like one-click buy, auto-fill price, historical price query, etc., to help players trade more efficiently in the auction house.

### Feature List

- **Quick Sell**: Auto-fill reference price, support one-click listing
- **Price Database**: Complete historical price records and trend analysis
- **Price Charts**: Visualize item price fluctuations
- **Disenchant Value**: Show estimated value of disenchanted materials
- **Shopping Lists**: Support multiple lists with import/export
- **Strategy Posting** (Pro): Auto-generate posting plans by strategy
- **Operation Maintenance** (Pro): Check auction status, record transaction ledger
- **Theme Switch**: Multiple UI themes available

### Supported Versions

- World of Warcraft Titan Classic (Interface: 38001)

### Installation

1. Download the latest version of the addon zip package
2. Extract to `World of Warcraft/_classic_titan_/Interface/AddOns/` directory
3. Ensure the directory structure is `AddOns/EasyAuction/EasyAuction.toc`
4. Launch the game and enable the addon on the character selection screen

### Usage

**Basic Operations**:
- The addon loads automatically when opening the auction house
- Click items to view historical prices and disenchant values
- Quick sell panel supports fast price filling and listing

**Commands**:
- `/epah` - Open price database
- `/easyauction` - Open settings panel
